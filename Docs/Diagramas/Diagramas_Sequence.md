**Descrição:**
Ele detalha a linha do tempo das interações entre o Usuário, a Interface, o Controller e a API de LLM. O fluxo demonstra a natureza moderna do app: a voz ou texto do usuário é processada externamente para extração de dados, retornando uma sugestão de venda que só é persistida no Banco de Dados após a validação humana. 
É uma peça fundamental para entender como a integração tecnológica resolve o problema da dificuldade de digitação manual na oficina.
